# StudyFlow AI

AI study planning assistant built with Python.

## Problem
Students struggle to organize exam preparation across multiple subjects and deadlines.

## Solution
StudyFlow AI analyzes exam calendars and generates personalized study plans.

## Features
- Student profile management
- Subject and CFU workload calculation
- PDF exam calendar extraction
- Exam scheduling optimization
- Study timeline generation
- Visualization of the plan

## Technologies
- Python
- PyMuPDF
- Matplotlib

## Example
Input:
7 exams, 4 hours/day

Output:
Personalized exam roadmap and daily study distribution.
